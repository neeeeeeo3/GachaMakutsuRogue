# ガチャ魔窟ローグ Prototype

Unityで制作中の2Dローグライク防衛ゲームのプロトタイプです。

ガチャでスライム・餌・罠を獲得し、地下ダンジョンを掘って、侵入してくる勇者からコアを守ります。

## Play Demo

https://neeeeeeo3.itch.io/gacha-makutsu-rogue

## 概要

- ガチャ筐体からユニットやアイテムを獲得
- 地下ダンジョンを掘って通路を作成
- スライム、餌、罠を配置して勇者を迎撃
- コアを守るローグライク防衛ゲーム

## 操作方法

- 左クリック：土を掘る / コアを置く / アイテムを置く
- 右クリック：配置キャンセル
- W / A / S / D：カメラ移動
- マウスホイール：ズーム
- GACHA：ガチャを回す
- SET CORE：コア設置
- START DEFENSE：勇者ウェーブ開始

## 開発環境

- Unity
- C#
- WebGL
- 2D
